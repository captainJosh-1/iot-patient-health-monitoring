# Clinical Dashboard Frontend

This directory is designated for the Doctor Patient Monitoring Dashboard Single Page Application (SPA).

## Planned Technology Stack
- **Framework:** React 18+ with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Component Primitives:** shadcn/ui (Radix UI)
- **Data Visualization:** Recharts
- **Cloud Backend:** Firebase Authentication & Firebase Realtime Database (`asia-southeast1`)

## Implementation Status
- **Status:** Scaffold placeholder (Phase 1).
- **Scheduled Implementation:** Phase 2 (Frontend Foundation) through Phase 6 (Real-Time Cloud Integration).
- **Rule:** Do not initialize or build application code in this directory until Phase 1 documentation is reviewed and approved.

Please refer to [Development Plan](../docs/DEVELOPMENT_PLAN.md) and [Architecture](../docs/ARCHITECTURE.md) for architectural guidelines.
